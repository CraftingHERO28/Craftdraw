# Craftdraw

A lightweight, distraction-free browser-based drawing application with a modern glassmorphism toolbar.

## Features
- **Fullscreen Canvas:** Automatically adapts to the viewport and preserves your artwork when resizing the browser window.
- **Multiple Tools:**
  - **Pencil:** For smooth, rounded strokes.
  - **Spray Can:** For textured airbrush effects.
  - **Highlighter:** Features a special `multiply` mode so that any text underneath remains perfectly readable and visible.
  - **Eraser:** For quick corrections.
  - **Text Tool:** For typing text directly onto the canvas.
- **Colors & Size:** Quick-select color swatches, a custom color picker, and smooth pixel size adjustments.

## Usage
Simply place all three files (`index.html`, `style.css`, and `script.js`) into the same folder and open `index.html` in your browser.
